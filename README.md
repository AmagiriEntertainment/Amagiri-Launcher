# Amagiri Launcher

**A better way to experience Minecraft.**

Welcome to **Amagiri Launcher**, a Minecraft launcher developed by **Amagiri Entertainment**.

Amagiri Launcher is designed to provide a simple and convenient Minecraft experience, with tools to manage game instances, install modpacks, and organize mods in one place.

## ✨ What is Amagiri Launcher?

Amagiri Launcher brings together the tools needed to manage your Minecraft experience.

Whether you enjoy vanilla Minecraft or modded gameplay, Amagiri Launcher aims to make setting up and managing your game easier.

## 🌟 Highlights

- **Instance Management** — Manage multiple Minecraft installations independently.
- **Modpack Management** — Install and manage modpacks with ease.
- **Mod Management** — Add, update, and remove mods from your instances.
- **Java Runtime Settings** — Configure Java runtime for your Minecraft instances.
- **CurseForge Integration** — Discover supported mods and modpacks through CurseForge.

## 🖥️ Platform

Currently designed for Windows desktop.
